# Yuki Takita

Java を中心とした業務系 Web システムの開発エンジニアです（実務経験 約6年）。
基本設計・詳細設計から実装、テスト、コードレビューまでを担当しており、直近ではリーダー／サブリーダーとしてチームの開発も取りまとめています。

## できること

- **バックエンド**：Java（Spring Boot / Struts）による画面開発・バッチ開発・REST API 連携
- **外部システム連携**：REST/JSON による外部サービス連携バッチ、XML 電文の作成と取り込み
- **テスト**：JUnit による単体テスト、テスト項目書の作成と結合テスト、Playwright によるE2Eテストの自動化
- **AI 活用**：Claude を使った開発と、生成されたコードのレビュー
- **その他**：Oracle、ShellScript、JavaScript / jQuery、Python / GAS による業務の自動化

## 主な経験

- **製造業向けワークフローシステムの初期構築**（Spring Boot）
  OCR システムとの連携バッチ（アップロード・結果の取得と反映）、外部チェックシステムとの連携バッチ、画面の改修
- **銀行間取引システムのマイグレーション**（VB6 / C → Java の Web システム）
  ISO 20022（pacs.009 / camt.057）に対応した送金機能や電文作成機能の開発、パッケージのカスタマイズ
- **Web システムのエンハンス開発**（Java / Struts / Oracle）
  設計から保守・運用まで
